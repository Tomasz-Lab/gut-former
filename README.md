# 🐍 MicrobiomeGPT

MicrobiomeGPT by TomaszLab

## 📋 Prerequisites

- [pyenv](https://github.com/pyenv/pyenv) - Python version management
- [Poetry](https://python-poetry.org/) - Dependency management

Both can be installed via `brew install pyenv poetry` or see links above.

## 🚀 Setup

```bash
pyenv install 3.12  # if not already installed
make install
```

## ▶️ Running the Project

```bash
poetry run microbiome_gpt
```

## 🔧 Troubleshooting

To start fresh (remove virtual environment and reinstall):

```bash
make clean
make install
```
